# Recall Atlas — Brand Usage and Product Copy

## Canonical usage

- Product name: **Recall Atlas**
- Tagline: **Find it. Understand it. Remember it.**
- Normal casing: Title Case for the name; sentence case for headings and UI.
- Do not alternate casually between “RecallAtlas,” “Recall-Atlas,” and “Recall Atlas.” Use `recall-atlas` only for technical slugs where appropriate.

## UI copy principles

1. Say what happened, what is happening, or what the user can do next.
2. Distinguish AI suggestions from confirmed facts.
3. Do not imply a question has an answer when answers are not part of the initial product.
4. Explain delays caused by background processing.
5. Use neutral, actionable moderation messages.

## Example UI copy

### Upload flow
- “Choose a document”
- “Review document details”
- “Your upload is being checked.”
- “Extraction is processing in the background. You can leave this page and return later.”
- “Some questions need review before they can be published.”
- “We could not confidently extract every question. The original document is still available to authorized users.”

### Search
- “Search questions, documents, and resources”
- “No matching results. Try a broader term or remove a filter.”
- “Semantic search is temporarily unavailable. Keyword search is still working.”

### Security and moderation
- “This file is being held for a safety review.”
- “Your report has been received. A report does not automatically mean the content will be removed.”
- “This action requires administrator approval.”
- “Access is restricted. If you believe this is an error, contact support.”

### Metadata
- “Suggested by AI”
- “Confirmed”
- “Unknown”
- “Needs review”
- “Source page”
- “Original document”

## Copy to avoid

Avoid “AI verified” unless a clearly defined verification process actually occurred. Avoid “100% accurate,” “instant processing,” “official school archive” without formal authorization, and any wording that implies an answer key is included.

## Example homepage content

**Recall Atlas**  
*Find it. Understand it. Remember it.*

Search past questions, source documents, and learning resources from your academic community.

Primary action: **Search the archive**  
Secondary action: **Upload a resource**

Suggested sections:
- Continue studying
- Recent questions
- Browse by grade and subject
- Recently added documents
- Study notes and articles
- Announcements and opportunities
- Your collections and bookmarks

## Accessibility and localization

The initial interface is English-only. Amharic documents may be uploaded, but extraction support should be clearly labeled as limited until it has been evaluated. Do not imply the entire product UI is multilingual in the first release.
